# Spécification de l'algorithme nafar (À RÉDIGER — prérequis sprint 9)

> Rédigé par le développeur / les oustaz. Claude Code ne doit pas inventer cet algorithme.

## 1. Vocabulaire
Termes utilisés dans les daaras (nafar, etc.) et leur définition exacte.

## 2. Unités de découpage
Comment la mémorisation est découpée (sourate, hizb, versets, page, portion écrite sur l'alluwa...).

## 3. Entrées
Données nécessaires : historique de l'apprenant, évaluations, niveau, rythme, objectif...

## 4. Règles
- Comment on choisit la prochaine portion nouvelle
- Quand et quoi réviser
- Critères de validation / d'échec, que se passe-t-il en cas d'échec
- Variantes selon l'âge ou le niveau

## 5. Sorties
Ce que l'algorithme produit (planning du jour/semaine, alertes, statuts...).

## 6. Exemples
Au moins 3 cas réels déroulés pas à pas (entrées → décisions → sorties). Ils serviront de tests.
